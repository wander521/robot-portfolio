让数据，来自真实世界。

我主导开发具身智能数据采集系统，围绕 Task、Dataset 与 Episode 组织机器人采集业务，连接任务分配、设备运行时、采集控制、上传转换、数据集管理与标注，让一次机器人操作成为可追踪、可管理的数据资产。

系统通过机器人客户端与 MQTT 事件连接设备侧执行，提供 Episode 启动、停止、取消与状态回传。我完成机器人租约互斥、幂等启动、超时兜底及通知路由，并接入按 Episode 上传与私有化 LeRobot 转换。围绕数据使用，开发数据集与标注管理、Rerun 可视化代理、设备指标查询，以及模型下载和真机演示接口。

我做了什么

采集任务与角色分配

建立 Task → Dataset → Episode 的业务关系，支持主账号分配采集任务、采集员访问本人任务，并按租户与角色约束设备、任务和数据集的可见范围。

机器人运行时与采集控制

对接机器人客户端、MQTT 事件和实时状态，完成 Episode 启动、停止、取消；用机器人租约控制并发，处理幂等启动、超时补偿与状态通知。

上传、转换与数据资产

按 Episode 下发上传请求，通过异步事件回写结果；接入私有化 LeRobot 转换，维护转换中、失败与完成状态，提供数据集查询和受权限保护的资源访问。

标注与可视化接入

实现标注任务、待标注项领取、结果提交与 Episode 管理，接入 Rerun HTTP / WebSocket 代理和机器人状态指标查询。

模型与真机演示

接入机器人模型下载、单机器人 WebSocket / SSE 演示与多机器人流式演示，转发任务解析、执行与完成事件，处理互斥、取消及部分设备失败。

Rerun 多模态回放

接入 Rerun 观测，沿统一时间轴查看顶部与左右腕相机、Action 与 State 曲线，关联 Episode 与任务上下文，辅助检查采集过程和操作状态变化。

系统如何协作

任务与权限

主账号创建和分配任务，采集员在授权范围内使用设备与采集条目。

采集 API 与运行时

FastAPI 组织 Task / Dataset / Episode；租约、状态机与机器人客户端控制采集生命周期。

设备与 MQTT 事件

下发采集指令，接收设备状态与执行事件，并将变化持久化、通知前端。

上传与 LeRobot 转换

按 Episode 上传，跟踪异步结果与私有化转换状态，形成任务关联数据集。

数据集与标注

管理采集数据、标注任务和结果；Rerun 代理与指标接口支持观测。

工程实践

用状态机约束采集过程

启动中、采集中、停止中与取消中是活跃态；已有活跃 Episode 会阻止冲突启动。重复启动可返回已有条目，超时路径释放租约并反馈可见状态。

把异步事件落回业务状态

机器人指令与业务状态分开管理；设备事件推动 Episode 持久化、上传收尾和前端通知，使采集链路具有可追踪的过程。

受控的数据访问

任务分配与数据集读取在服务端检查角色、租户和资源归属；数据资源访问与业务权限协同，避免仅依赖页面筛选。

把演示与数据采集分别建模

真机演示有独立的任务事件流和互斥控制；多机器人广播汇总跳过原因，展示机器人的事件驱动前端，并在结束或断开时取消其他任务。
