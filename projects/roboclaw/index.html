从语言到行动

我负责 RoboClaw 的整体设计与开发，基于 Nanobot 构建面向真实机器人的具身智能交互与任务执行系统，打通语言交互、Agent 编排、机器人网关与真机执行，并完成 SLAM 建图与定位接入、导航、展厅讲解、路线巡检、实时语音、抓取和 VLA 推理服务接入等工作。

RoboClaw 将自然语言理解、多模态感知、任务编排与机器人执行连接成完整的应用链路。围绕空间服务场景，我对接机器人端 SLAM 服务，开发地图、定位与点位导航能力，再将它们编排为展厅多站导览和路线巡检：让机器人能够使用选定地图，到达目标位置，播放讲解并配合动作，或采集仪器画面、记录巡检结果。配套的独立巡检平台与 G1 Edge Agent 进一步承接地图点位管理、任务下发、步骤状态和设备端反馈。

展厅讲解与多站导览

开发按地图组织的导览点位、站点顺序与音频配置，支持自然语言发起参观或指定主题的单点讲解；将点位导航、讲解音频播放和手臂动作组织为导览流程，并在独立平台中接入到站后的 TTS 站点动作。

实时语音与 VLA 服务接入

接入千问实时语音，完成 App 会话控制和机器人音频链路；对接 VLA 推理服务，使受支持任务能够进入真机执行流程。

处理跨运行环境的机器人音频链路

通过独立播放进程协调机器人 SDK 与网关的 Python 运行环境，完成实时语音会话与设备扬声器输出。

把空间能力编排为可追溯的场景任务

地图、点位、讲解音频和巡检步骤使用同一场景配置。独立平台对任务保存路线点位快照，Edge 逐站执行并依据实际位姿确认到达；定位缺失、过期或导航失败时保留明确状态，避免用固定等待时间代替执行结果。

我做了什么

智能交互与任务编排

扩展 Agent 与技能/工具调用链路，将用户指令、会话上下文和机器人状态连接到具体任务执行。

机器人网关与硬件适配

开发 FastAPI 控制网关与机器人适配，封装移动、旋转、手势、动作与状态查询等能力，对接 Unitree G1 的底层控制接口。

感知与抓取能力集成

建设图像与点云相关服务，集成目标识别、坐标转换、手臂与末端执行控制，组织抓取、收臂和递交物品等动作流程。

SLAM 建图、定位与自主导航

对接 G1 的 slam_operate 服务，封装开始/结束建图、地图保存、重定位、目标位姿导航与暂停/恢复；开发多地图生命周期、点位采集与路线管理，并接入 ROS2 点云和位姿状态。底层 SLAM 与规划来自机器人平台，我负责应用接入与执行流程。

展厅讲解与多站导览

开发按地图组织的导览点位、站点顺序与音频配置，支持自然语言发起参观或指定主题的单点讲解；将点位导航、讲解音频播放和手臂动作组织为导览流程，并在独立平台中接入到站后的 TTS 站点动作。

路线巡检与独立中枢平台

开发配置化巡检流程，将到点导航、仪器画面采集、指示灯状态判定与结构化结果记录连接起来；研发独立 FastAPI/SQLite 巡检平台和 G1 Edge Agent，支持地图/点位/路线管理、任务步骤、逐站执行、到达确认、状态回传与急停操作。

实时语音与 VLA 服务接入

接入千问实时语音，完成 App 会话控制和机器人音频链路；对接 VLA 推理服务，使受支持任务能够进入真机执行流程。

工程可靠性与部署

围绕参数校验、动作白名单、安全状态、停止接口、位姿有效性与服务健康状态处理执行边界，提供设备端部署与服务管理。

HiRobo Android 移动端链路

连接 HiRobo 的设备状态、多模态会话、遥控动作、自定义 Ability、技能与任务历史入口；由 Gateway 接入 AppChannel / MessageBus / AgentLoop 或直接控制接口，再组织设备端执行与结果回传。

双臂抓放状态机

组织初始化、观察、左右臂抓取、结果判断与分类放置；对接 RGB-D 与外参坐标转换、抓取姿态、Curobo 轨迹规划和 Piper 夹爪控制，并维护重试、放置与回撤流程。
