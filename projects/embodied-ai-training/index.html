能力与流程教学工作流

让学习，发生在机器人上。

我主导设计和开发具身智能实训平台，将课程内容、班级教学、学习进度与机器人实验入口连接起来。教师导入课程包并安排教学，学生在授权课程中学习、提交产物，也可以进入自己绑定机器人上的 Notebook 调试 ROS 2 代码。

平台采用 React 前端与 FastAPI 模块化单体，使用 Casdoor 认证，MySQL 保存教学关系与记录，Redis / RQ 处理课程包导入，S3 管理课程资源。课程、班级、学习、文件与统计通过明确的模块接口协作。我完成一人一机 Notebook MVP 接入，通过受保护的 HTTP 与 WebSocket 代理把实验章节连接到机器人 Jupyter 内核；波纹步态课程已记录本地学生浏览器 → Notebook → ROS 2 → 实机动作与停止的闭环验收。集群代理与生产部署仍需独立验收。

我做了什么

课程包与教学内容

设计 ZIP 课程包规范和机器可读契约，开发异步解压、校验、资源入库、课程元信息确认、发布与公开课程浏览。

班级、选课与访问权限

实现教师班级组织和排课、学生有效选课关系，以及移出成员、取消课程和结束班级时的权限撤销与历史保留。

学习与提交闭环

开发章节开始、显式完成、实验资源下载和一次性提交确认；教师统计展示班级进度与提交，不将代码运行自动认定为成绩。

一人一机 Notebook 实验

按 Casdoor sub 选择学生绑定机器人，经课程权限复核后打开同源 JupyterLab；代理 Notebook HTTP 与内核 WebSocket，接入本地联调快速重连。

前后端与工程架构

实现教师、学生、维护人员共用的前端，组织 FastAPI 领域模块、RQ Worker、OpenAPI / JSON Schema 契约和容器交付配置。

系统如何协作

身份与角色前端

Casdoor 登录；教师、学生、维护人员使用同一 React 应用。访客可浏览公开课程。

课程与班级服务

FastAPI 模块化单体组织导入、发布、班级、排课和资源权限。

课程资源与异步导入

RQ Worker 校验 ZIP 课程包；MySQL 保存业务记录，Redis 管理队列，S3 保存文件。

学习与实践网关

有效选课关联章节进度、实验资源与提交；Provider 选择授权的实验入口。

机器人 Notebook 与统计

一人一机 Jupyter 内核执行 ROS 2；平台记录学习和提交，供教师查看。

工程实践

模块化单体，边界明确

课程、班级、学习、文件与统计保留在同一 API 内；跨模块通过 service / ports 协作。API 与 RQ Worker 共用代码并独立运行。

内容与权限生命周期一致

课程发布锁定可编辑元信息；班级排课保存课程版本关系。移出学生或取消课程撤销后续访问，保留学习、提交与审计历史。

把实验入口接到真实内核

Notebook Provider 校验选课和绑定；启动入口、HTTP 请求与 WebSocket 握手受保护。机器人内核执行 ROS 2，浏览器不接收 SSH 或 Jupyter 凭据。

清晰的验收边界

本地单学生、单机器人 Notebook 动作与停止链路已有验收记录。首期不含多学生调度、自动评分或通用机器人控制，生产集群接入仍待验收。
